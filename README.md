# 🛍️ ShopEasy – E-Commerce Landing Page

ShopEasy is a modern and responsive e-commerce landing page built using **HTML5 and CSS3**. It features a clean shopping interface with product cards, promotional banners, shopping categories, newsletter subscription, and a footer section.

## ✨ Features

- **Navigation Bar** – Logo, navigation links, search, wishlist, and cart icons.
- **Hero Banner** – Promotional banner with a shopping call-to-action.
- **Shopping Facilities** – Free shipping, secure payment, 24/7 support, and easy returns.
- **Featured Products** – Product images, names, ratings, prices, wishlist icons, and Add to Cart buttons.
- **Collection Section** – Separate collections for men, women, and electronics.
- **Newsletter Subscription** – Email subscription section for updates and offers.
- **Footer Section** – Quick links, customer service, social media icons, and contact information.
- **Bootstrap Icons** – Icons for shopping, navigation, ratings, and social media.
- **Custom Styling** – Consistent colors, spacing, borders, and typography using CSS.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap Icons 1.11.3

## 🚀 How to Run the Project

1. Clone the repository:

   ```bash
   git clone <your-repository-url>
   ```

2. Open the project folder:

   ```bash
   cd ShopEasy
   ```

3. Open `index.html` in your browser.

   Alternatively, use the **Live Server** extension in Visual Studio Code.
